# TypeScript-oefening

1. Pak alle bestanden uit in de hoofdmap van je gekloonde Classroom50-repository.
   Neem ook `.gitignore` over. Behoud de bestaande `.git`-map.
2. Open die map in VS Code en voer `yarn` uit om TypeScript lokaal te installeren.
3. Werk de opdrachten uit in `typescript-starter.ts`.
4. Controleer je types met `yarn typecheck`.
5. Voeg zelf controles toe. Compileer met `yarn build` en voer je code uit met
   `yarn start`. Compileren lukt pas wanneer de TypeScript-fouten opgelost zijn.
6. Commit ook je configuratie en het gegenereerde `yarn.lock`, maar niet
   `node_modules` of `dist`.

De starterscode is bewust onafgewerkt. Typefouten bij de eerste controle zijn
normaal. Er zijn geen tests meegeleverd; schrijf zelf controles zoals gevraagd
op de oefenpagina.

## Oplevering

Vul deze README aan met je naam en een korte uitleg over één keuze die je maakte.
